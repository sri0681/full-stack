Animations:
    ->@keyframe myName{
        form{
            font-size: 20px
            }
        to{
            font-size: 40px;
        }
    }

    -> properties:
    i. animation-myName
    ii. animation-duration
    iii. animation-timing-function
    iv. animation-delay
    v. animation-iteration-count
    vi. animation-direction

    ->% in animation:

    @keyframe myName{
        0% {font-size: 20px;}
        50% {font-size: 30px;}
        100% {font-size: 40px;}
    }
    
    position
    - static : default position(the top, bottom, left and z-index properties have no effect)
    - relative : element is relative to itself ( the top, right, bottom, left, and z-index will work)
    - absolute : positioned relative to its closed positioned ( removed fromt the flow)
    - fixed : positioned reltive to browser
    - sticky : positioned based on users scroll position
